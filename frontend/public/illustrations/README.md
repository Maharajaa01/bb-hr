# Illustrations

Original line-art illustrations drawn for BB HR (no third-party artwork, no licence or credit needed).
They are generated by `scripts/make_illustrations.py` — edit that script and run
`npm run illustrations` to change them; do not edit the SVGs by hand.

Style: 1.5px `#263238` outlines, brand blue `#048EFF` / light blue `#A8D5FF` fills, orange `#F2A23A`
accents, soft `#EAF5FF` background blobs. Served as `<img>` and precached by the service worker.
