# Illustrations

Spot illustrations from [unDraw](https://undraw.co) by Katerina Limpitsouni, recoloured to brand blue
`#048EFF` (unDraw's default accent `#6c63ff` replaced). unDraw's licence allows commercial use without
attribution; see https://undraw.co/license. Do not bundle these into a redistributable pack.

To replace one: download the SVG from undraw.co (set the colour to `#048EFF` on the site, or replace
`#6c63ff` afterwards), save it here under the same file name, and rebuild. Served as `<img>` and
precached by the service worker.
